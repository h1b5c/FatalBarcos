# Fatal Barcos
Casa de barcos (noturna)
Este é o projeto final para a disciplina de Banco de Dados II, no qual desenvolvemos um banco de dados para uma locadora de barcos utilizando o Oracle SQL Developer. O projeto abange a ciração de um banco de dados e de suas restrições a partir de uma situação fictícia, incluindo criação de diagramas, scripts para criação, população, manipulação e documentação detalhada.
